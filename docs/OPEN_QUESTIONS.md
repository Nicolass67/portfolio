# Questions ouvertes

## Q-18 — Accent de marque public

- Comparaison via l’explorateur **Accent** (mode démo uniquement).
- Palette : ~30 teintes (bleus, cyans, violets, chauds, verts, rouges, neutres) + couleur libre.
- Recommandation agent : **outremer** (`ultramarine` / `#2146d6`) — lisible sur fond light, cohérent avec studio.
- Alternatives contrastées à tester : teal, crimson, amber.
- Après choix : figer `--accent`, retirer l’explorateur, régénérer captures.
